# 学习记录存储与检索

新记录的对话JSON先编码为UTF-8，再使用Python标准库zlib（级别6）压缩，加上版本前缀MGZ1。只有包含前缀的压缩结果比原始UTF-8短，才以SQLite BLOB保存；短记录保留TEXT。读取时依据类型和前缀自动解压，对外仍返回原来的JSON字符串。

旧记录无需重写，原TEXT直接读取。现有库的旧记录不会自动压缩，因此新增压缩不等于数据库文件立即缩小。压缩率取决于实际对话内容，不承诺固定比例。压缩不属于加密。

日期、题型、知识点及掌握状态保持普通列。历史查询通过参数化SQL筛选日期和题型，再解压命中的对话；日期和题型增加联合索引。薄弱点统计直接聚合字段，无需解压对话。当前历史接口仍返回所有匹配记录，未实现分页。

公式库独立于对话压缩：模型从50条编号目录选择知识点，Python校验编号，再通过SQLite主键查询公式。未命中可使用已有名称别名兜底。这不是向量检索，也不让模型扫描压缩记录。

测试覆盖中文长对话无损恢复、实际保存为BLOB、短文本不增大、旧TEXT兼容、重启初始化、日期/题型筛选与薄弱统计。损坏数据明确报错，不静默替换为空记录。
