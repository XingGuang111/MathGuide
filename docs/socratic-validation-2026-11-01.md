# MathGuide：按学生回复生成引导与学习档案实测

> 本文所列 `output/` 中的日志、截图和录屏是本地历史验证产物，不包含在 GitHub 源码下载中。当前安装验证结果请参阅 [安装与启动验证记录](installation-verification.md)。

日期：2026-11-01；模型：本机 Ollama `mathguide-qwen25-3b:latest`。

学生输入来自测试脚本，教师回答来自实际本地模型。本文及关联记录均为产品测试，不代表真实学生学习表现。没有手工编写教师回答、替换模型返回或直接插入学习记录。

## 本次变化

- 每轮调用模型分析学生原话及近期对话，再由模型生成回答；固定话术只作教学提醒，程序核验算式、结果、阶段及重复问题。
- 结果正确后只处理缺少的单位，保留正确算式；小例子完成后返回原题，不继续循环同一个例子。
- 重写时保留学生分析与程序核验事实，明确当前阶段；模型失败时返回可重试状态，不伪装为成功或掌握。
- 区分找公式、列算式、计算结果三个提问目标；清除完全重复句子，对已算对数值的轮次移除多余数量追问，保留模型生成的单位提示。
- 诊断使用 JSON Schema 限制字段与枚举；完整讲解使用单独提示，消除与“不给答案”的冲突。步骤编号不当作新增数学数字。

## 失败与修复记录

首次补单位提示存在矛盾：提示直接给单位，校验又要求引导学生补齐；重写还可能拿回旧的数量问题。已统一目标并保留学生上下文。失败样例（本地文件：`output/socratic-2026-11-01-final2/transcripts.md`）。

多轮测试发现正常的“同样多”概念解释被误拦、公式提问与列式提问被当成重复、小例子答对被当成原题答对、讲解步骤编号被当成新数字。分别修正相应边界，并增加回归测试。所有中间日志保留在 output/socratic-*，没有覆盖失败报告。交付前失败记录（本地文件：`output/socratic-2026-11-01-delivery/transcripts.md`）、后续复测（本地文件：`output/socratic-2026-11-01-delivery-retest/transcripts.md`）。

档案首次录入时，面积讲解未给完整计算；鸡兔同笼诊断返回不合规。已分离完整讲解提示、约束诊断格式，再通过正常 API 复测归档，原失败会话未伪装为已完成。

## 展示与质量边界

最终 8/8 是本轮脚本检查结果，不代表所有表达都已达到人工教学质量，也不代表本地小模型永不重复。此前多轮结果存在波动。追及题曾在学生给出完整答案后额外追问；部分回复仍偏泛化，复杂数学表述需继续扩展实测。学习档案的“独立解出”在本次展示中指脚本提交完整作答，不能作为真实学生掌握能力的证据。

展示可先看薄弱点与学习轨迹，再打开折扣的纠错过程、鸡兔同笼的完整解题记录及面积“讲解后复习”记录，说明不同状态的来源。
