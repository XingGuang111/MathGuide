# 常见题型计算核验

当前支持明确给出长和宽、两者同单位的长方形单步面积或周长题，例如“长方形长8厘米，宽3厘米，面积是多少？”支持十进制数，计算使用Fraction精确值，不执行学生表达式。

支持题型的学生回答由Python核验，不依赖模型状态标记：

- 面积算式如 `8×3=24平方厘米`，或 `面积等于长乘宽，8乘3等于24平方厘米`。
- 周长算式如 `(8+3)×2=22厘米`。
- 算式中的长宽必须与题目一致，计算结果和单位必须正确。
- 仅说“懂了”、只给结果、缺单位、单位错误、错误数字或其他不能解析的表达不会结束辅导。
- 达到轮数上限时，Python生成公式、代入、答案和单位检查，按未独立理解归档。

题目分析和开场仍使用Ollama。不支持缺条件、混合单位、面积和周长同时求解、阴影部分、多步变化等题目；识别条件不满足时保留原模型辅导流程。不能解析的正确自然语言也可能被要求重写，这是一条受控验收路径，不是通用解题器。当前需要在同一条回答中给出算式、结果与单位。

测试：`python -m pytest -q`。真实模型加完整Web API验收：`python tests/model_flow_smoke.py`，使用临时库验证两个题型的开场、错误答案继续、完整作答结束、归档和历史回放，不改动真实记录。
