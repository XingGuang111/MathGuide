## 一、项目核心优势（直接可以放进论文，分工程层面、AI教育层面）

工程层面优势

1. 离线本地部署，隐私性强
采用Qwen1.5-4B本地运行，不需要调用云端大模型API。学生的题目、作答对话、错题记录全部保存在本地SQLite数据库，不会上传第三方服务器，适合教育场景保护学生学习数据；同时无网络也能使用，不存在API调用费用。

2. 解耦设计，规避大模型幻觉
把公式、知识点从大模型生成逻辑剥离，存入SQLite知识库。
大模型不再负责“创造公式”，公式由程序查表获取，解决小模型容易写错公式的幻觉问题。
这是本项目很关键的创新取舍：把确定性任务交给程序，不确定性自然语言任务交给大模型。
3. 前后端分离标准化软件工程架构
Vue3前端 + FastAPI后端，模块化拆分（OCR模块、Agent模块、数据库模块），不是简单低代码平台拖拽Demo，软件架构规范，可维护、可扩展。

4. 学习数据自动归档，支持多维度复盘
自动按日期、题型存储完整对话日志，统计薄弱知识点，形成学习档案，方便学生复盘错题。

教育层面优势（最大亮点，区别普通搜题软件）

市面上拍照搜题产品核心逻辑：拍照→识别→直接给出答案，学生容易抄答案，不利于思考。
本系统：拍照识别 → 展示固定公式 → Agent启发式引导提问，不直接输出答案。
遵循苏格拉底式教学，引导学生自主推导，侧重思路训练，而不是直接获取结果，契合新课标启发式教育理念。

## 二、项目有没有发挥大模型的优势？

有，而且精准利用了大模型擅长的能力，避开它的短板。
先区分：大模型擅长什么、不擅长什么
✅ 大模型擅长：

1. 自然语言理解：读懂应用题文字，识别题目对应的知识点、题型

2. 多轮对话理解：读懂学生自然语言的回答，判断学生思路对错

3. 自然语言生成：用小学生易懂的语言，提出引导性问题，而不是生硬冰冷的机器问答

4. 生成变式练习题：用不同文字场景包装同一个知识点，生成新练习题

❌ 大模型不擅长（本项目刻意规避）：

1. 精确数学计算（交给Python代码，后续可做计算器工具）

2. 记住固定公式（交给SQLite知识库查表）

3. 严格确定性逻辑推理（小学短推理可以，复杂推理不依赖）
一句话概括：
不把大模型当做“计算器/知识库”，而是把大模型当做「自然语言辅导老师」。
知识库、精确计算交给传统程序；大模型承担语义理解、多轮对话、启发式引导、变式题生成这些传统程序很难实现的能力。
这正是发挥大模型的核心价值。
详细拆解大模型在项目里承担的4项核心工作

1. 理解自然语言题干，识别知识点与题型
传统规则匹配很难处理应用题多样化的文字描述（同样长方形面积题，题干说法千变万化）。
用正则很难全覆盖；但大模型可以读懂文字语义，输出标准化知识点名称，再映射到知识库。
👉 这是传统硬编码规则很难做到的。
2. 多轮对话，动态理解学生的回答，动态调整引导话术
学生的回答是自由文本，回答五花八门：可能只说一个数字、只说半句话、思路部分对部分错。
传统if-else分支根本穷举不完学生的回答；大模型可以理解学生表达，针对性提问引导。
👉 这是Agent最核心价值，也是传统程序最大短板。
3. 用适合小学生的通俗语言进行引导
可以根据学生水平调整话术，语言口语化，不像机器死板。比如学生混淆周长和面积，模型可以用通俗提问，而不是固定一句话。

4. 动态生成同知识点变式题
同一个知识点，可以换场景、换数字生成新应用题。如果纯传统程序写变式题，需要提前录入海量例题库；大模型可以现场生成，减少题库录入工作量。

## 三、论文可写：对比传统方案，突出价值

1. 对比传统固定题库系统
传统错题辅导系统：题目、提问全部提前写死，交互是固定脚本，无法响应学生自由回答。
本项目：依托大模型实现动态对话，针对学生不同作答实时调整引导问题。

2. 对比云端大模型搜题应用
云端搜题依赖网络，学习数据上传云端；本系统本地离线运行，隐私安全。

3. 对比纯规则Agent
纯规则系统很难处理学生自然语言输入；本项目利用大模型语义理解能力，实现自然交互。

## 四、客观局限（论文“不足”章节，如实写）

1. 大模型仍然存在少量幻觉，在生成引导话术、变式题时偶尔会出错，所以通过知识库分离确定性任务降低风险；

2. 受Qwen1.5-4B模型规模限制，复杂长推理题目效果有限，因此系统限定为小学课内题目；

3. 模型无法解析图片内几何图形，仅能处理OCR识别后的文字题干。

## 五、浓缩版（答辩口述，简短）

本项目充分发挥大模型自然语言理解与多轮对话生成的优势。
传统程序很难理解学生自由作答、动态生成启发式提问；而大模型可以像老师一样和学生对话。
同时我们规避大模型短板：公式、精确计算交给传统程序和数据库，减少幻觉。
和市面上直接给答案的搜题软件相比，系统以启发式教学为核心，引导学生自主思考；并且本地离线部署，保护学习隐私。
