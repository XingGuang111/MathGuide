## 运行

```powershell
python -m pip install -r requirements-dev.txt
python -m uvicorn web_app:app --host 127.0.0.1 --port 8000
```

打开 `http://127.0.0.1:8000`。没有模型时可以打开首页、查看学习记录、使用 OCR 和完成专项练习，辅导请求会给出服务不可用提示。更新后需要重启服务，启动时自动创建练习表并保留旧数据。

数据库在 `data/mathguide.db`，会话快照在 `data/mathguide.sessions.json`。两者包含学习内容，均不应提交版本库。服务使用单个进程，启动时不要添加 `--workers`；这是单机演示版，未包含多用户账号和权限隔离。前端采用原生 HTML/JavaScript，尚未迁移 Vue3，该迁移不影响本轮功能范围。
