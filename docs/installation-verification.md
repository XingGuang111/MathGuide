# 安装与启动验证记录

本记录区分已验证结果与仍未验证的步骤，避免将开发环境可运行等同于所有新设备可用。

## 验证环境与方法

- Windows，64 位 Python 3.12.10，Ollama 0.40.13。
- 新建 `.venv`，未启用系统 site-packages；从 `requirements-dev.txt` 安装运行及测试依赖。
- 默认 PyPI 下载较慢，安装依赖改用 README 中列出的清华镜像。
- 将当前源码、公式种子、教学资料和网页素材复制到独立目录，不复制原有学习数据库或会话快照。
- 在独立副本中启动真实 Uvicorn HTTP 服务，使用真实 Ollama 与 RapidOCR；未修改日常学习数据库。
