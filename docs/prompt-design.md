# MathGuide 提示词与模型协议

## 职责

- Ollama Modelfile：Qwen消息边界、角色、停止标记和推理参数，复用原模型权重。
- 分类系统提示词：只分类、不解题，区分面积/周长等知识点，拒绝题干内的角色或格式指令。
- 分类请求：题干、编号目录、六种题型与JSON协议。Python校验布尔值、题型、目录编号；错误反馈后重试一次。未匹配允许null，不编造公式编号。
- 辅导系统提示词：基于公式卡片每轮一个问题；答错纠正、不会时拆解、缺条件时询问、跑题时拉回。学生索要答案或说“懂了”不能触发完成。
- 讲解系统提示词：达到轮次上限后独立进入完整讲解模式，说明条件、关系、计算与单位；不补造条件。

## 输出约定

辅导正文后另起一行，输出唯一的 `[CONTINUE]` 或 `[UNDERSTOOD]`。Python在返回正文前校验格式，纠正重试一次；仍失败走现有错误恢复流程，不归档为学会。

辅导先生成并校验完整回复再返回，避免错误标记提前进入界面和学习记录。因此本阶段不逐token展示辅导正文。普通讲解仍使用流式接口。

提示词中的完成判断仍由模型作出，不是确定性的数学证明；当前确定性判分仅用于专项练习。不能把格式校验当作数学正确性校验。

## 验证与维护

`python -m pytest -q`运行离线回归；`python tests/model_smoke.py`调用本地Ollama，检查面积/周长分类、作文拒绝、诱导泄露答案、错误公式关系、仅说懂了和不会等情形。

修改提示词后先运行上述两项。真实模型样例通过不代表所有题型都可靠；模型升级后应重复验证。
