# 薄弱知识点练习闭环

## 流程

1. 从历史辅导与专项练习结果计算当前复习优先分。
2. 优先选分数最高且公式库中存在的知识点，无薄弱点时安排基础练习。
3. 使用知识点对应的受控题型改变数字，尽量避开最近5道同知识点题。
4. Python计算精确标准答案，题目API只返回题干与作答单位。
5. 学生可查看提示，服务端记录提示使用情况，不能由客户端撤回。
6. 首次有效答案在SQLite事务中判分，重复或并发提交最多计入一次。
7. 更新复习优先分和连续独立正确数，反馈参考答案与计算思路。

## 模块与保存

- `practice.py`：参数化出题、答案格式校验、精确计算、判分。
- `db.py`：新增`practice_exercise`表，不改变或删除旧学习记录；统计融合两个数据来源。
- `web_app.py`：新增练习、恢复、提示与答题API。
- `web/index.html`、`web/app.js`：练习对话框、提交、反馈、统计刷新。

练习表保存知识点ID、题目及内部答案JSON、提示标记、学生答案、判分与时间。数据库重新初始化不会删除练习，恢复入口不泄露答案。当前服务为单用户本机场景，不构成多用户安全系统。

## 能力边界

50个知识点各有一种参数化练习，改编数字但没有借助模型任意重写原错题。判分支持整数、小数、分数及指定单位，不执行输入表达式、不评估自然语言推理过程。分数使用精确比较，重复小数要求用分数。查看提示后答对不视为独立答对。连续3次正确标记仅是复习规则，后续需要延迟测验与教师评价验证。

专项练习结果保存在独立表，与辅导记录区分。界面的历史记录仍只展示辅导归档；专项练习统计展示在薄弱点面板，答题结果展示在练习页。

## 手工验收

启动单进程Web服务后，检查无模型时能出题、查看提示后独立正确次数不增加、连续独立答对3题后状态更新、答错后重新复习、刷新恢复未提交题目、已提交题目不能重复计数。检查旧的文字辅导、OCR、历史查询和快照恢复不受影响。
